# FrameMind Studio 0.1.7

14 November 2026 · Windows x64 · unsigned development preview · culling `local-2.0`

## Photo-by-photo review

After local analysis, **Photo by photo / Fotka po fotce** opens with the current
photo, its explained suggestion and a queue of all photos. K/R/X or the decision
buttons save a manual choice and advance. Repeating a choice keeps it set.
Arrows navigate the full set; the back button and queue allow revisiting photos.
The final decision opens a summary. Reviewing again preserves manual choices.

**Whole set / Celá sada** opens the existing grid, profile, intent and comparison
controls. **Deliver as / Odevzdám jako** in the header rescores for 100%, A4 print
or web without measuring again. The sharpness map is available when optical
measurements are reliable. **Detail 1:1** opens the original viewer at 100%.

Continuing from the summary confirms removal of rejected photos from the working
set before opening the editor. Cancelling preserves the set; editor Undo restores
removed photos and their culling metadata. Original disk files are kept.

## Local automatic analysis

This release includes the previously unpublished local U²-NetP salient-region
model, measured original-size detail, up to four optional manual regions,
per-photo intent and verified identical-copy checks. Edge blur is measured in
pixels across the frame and object, then judged at the delivery size.
Manual decisions remain authoritative. Existing automatic results need a fresh
analysis. See the [culling guide](../culling.md) and the
[dated implementation history](unreleased.md).

The model does not recognise eyes, expressions, decisive moments or artistic
intent. Limited local calibration is not general photographic-accuracy evidence.
RAW uses the embedded JPEG preview, not developed sensor data.

## Download and limits

[Download v0.1.7](https://github.com/Lukedaca/framemind-studio/releases/tag/v0.1.7)
and compare the installer with `SHA256SUMS.txt` attached to that release.
The 237.68 MB installer includes the offline WebView2 installer and the bundled culling model.

The Windows installer is unsigned. A signing certificate is not configured;
signed client distribution, clean Windows installation without an existing
WebView2 runtime and every GPU configuration remain unverified. Do not disable
Windows protection. This release does not install itself into an existing local
workspace; updates use the installer manually.

The entire Studio is not fully offline: retouch/lasso models and fonts may be
downloaded, and two optional editor operations use Gemini with the user's key.
No cloud sync or public gallery hosting is added. Local data and disk originals
retain their documented boundaries.
