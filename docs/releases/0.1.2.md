# FrameMind Studio 0.1.2 — 15 October 2026

Windows x64 development release. The installer is unsigned; this is not a
signed client distribution. [Download and SHA-256 checksums](https://github.com/Lukedaca/framemind-studio/releases/tag/v0.1.2).

## Changes

- Adjustment previews use a cached decoded source in a worker, a maximum long
  edge of 1600 px, and the same rendering code as export. Obsolete preview
  requests are replaced by the latest one. Export uses the selected full size.
- Adjustments, auto adjustment, cropping, retouching and original restoration
  share Undo/Redo history. One slider gesture is one step; up to 60 steps are
  retained in each direction.
- IndexedDB stores projects, the workspace, image copies and edit history in
  the local application profile. Image assets are separate from edit metadata.
  Completed saves are confirmed; errors can be retried. Legacy JSON metadata
  remains intact, but missing legacy image bytes require reimport.
- Retouch working copies use lossless PNG. Non-square model crops retain
  their proportions with reflected padding. ONNX runtime assets use explicit
  matching local URLs; temporary tensors are disposed after each run.
- Culling engine `local-1.2` adds sampled 384 × 384 crops at original resolution
  for larger images and compensates small image shifts when comparing series.
  Explained reject suggestions remain editable; removing files from a set
  requires confirmation and never deletes the original disk files.

## Verification

TypeScript, 136 tests across 21 files, and web/desktop frontend builds passed.
Synthetic browser checks exercise preview/export parity, history, persistence,
save failure/retry, and both real inpainting models through CPU/WASM.
Retouch tests found zero changed pixels outside the patch, zero changes after
four PNG saves, and unchanged original hashes through brush, Undo/Redo and reload.

Native installation and runtime evidence is recorded in [the Windows guide](../desktop.md).
The native installer contains an offline WebView2 prerequisite; clean Windows
installation without a pre-existing runtime and a signed client release remain unverified.

## Limits and data

No full RAW development, cloud synchronization, or shared public galleries.
Retouch model input remains 512 × 512; large fills are limited by that resolution.
Synthetic checks do not establish photographic quality on real shoots or
compatibility with every GPU. The verified model path was CPU/WASM.

Ordinary work is local. Retouch/lasso models download from Hugging Face and fonts
from Google Fonts. Text-based photo edits and object search still use optional
Gemini calls with the user's own API key. See the current README for data flows.

Updating preserves the application identifier and origin. Do not clear the local
profile when updating. Keep originals and independent backups: local working
copies are not cloud storage, and GitHub does not back up private photos.
