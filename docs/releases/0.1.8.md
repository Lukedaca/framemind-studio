# FrameMind Studio 0.1.8

21 November 2026 · Windows x64 · unsigned development preview · culling `local-2.0`

## Adaptive strictness and optical defect detection

Release 0.1.8 extends the `local-2.0` local culling engine introduced in [0.1.7](0.1.7.md):

- **Automatic batch-adaptive strictness (`Auto`) + manual override (`Conservative / Balanced / Strict`)**:
  `recommendCullingStrictness` inspects the set's optical blur baseline, sharp share, noise level and
  series density to pick the appropriate strictness automatically — without any fixed reject quota
  (an all-sharp set still rejects 0 photos). Switching strictness or delivery output rescores immediately
  without remeasurement.
- **Directional motion blur (`subjectDirection`)**: `opticalMotionBlur` reads the four orientation bins
  measured by `cullingOptics.ts` so linear motion blur is detected instead of masked by sharp edges
  parallel to movement. Intentional motion, creative and stacking intents remain protected.
- **Back-focus / out-of-focus subject & higher-ISO tolerance**: distinguishes mild softness (`Review`)
  from strongly out-of-focus subjects (`Reject`) even beside a sharp background, removes false texture
  vetoes on blurry high-contrast frames, and raises the blur-evidence noise ceiling for realistic higher-ISO
  shooting while keeping extreme noise protected.
- **Optical series comparison**: verified burst series prefer optically sharper subjects and can reject
  substantially softer alternatives directly against a sharp representative.

The bundled U²-NetP model and local optical measurements do not recognize eyes, expressions, decisive
moments or artistic intent. Limited local calibration is not general photographic-accuracy evidence.
RAW import continues to use the embedded JPEG preview, not developed sensor data.

## Workflow and darkroom interface

- **Photo-by-photo focus mode**: queue filter (`All / Review / Reject / Keep / Undecided`) with live
  counts, inline series indicator and one-click/shortcut series comparison (`C`), direct editor handoff
  button, shortcuts (`Z` or click for 1:1 on the detected subject/focus point, `M` for blur map,
  `Backspace` for step back, `Ctrl+Z` for Undo, `?` for shortcut help), and photographic EXIF strip
  (`1/1600 s · f/2.8 · ISO 800 · 200 mm`).
- **Whole-set Contact Sheet (Light Table)**: unobstructed photos with a 2 px top status bar and matte
  metadata footer below the image; expanded series open at the top of the viewport; live ETA during
  analysis; unified amber color for `Review`.
- **Darkroom UI & cross-app flow**: quiet obsidian active sidebar state with spectral edge hairline,
  non-clipping segmented controls, single-row editor header, non-overlapping top-right notifications,
  explicit *Add to current set / Start new set* choice on import, smart culling restore on launch, and
  *Apply to whole set* in `AdjustPanel` with edited indicators on the filmstrip.

## Download and limits

[Download v0.1.8](https://github.com/Lukedaca/framemind-studio/releases/tag/v0.1.8)
and verify the installer against `SHA256SUMS.txt` attached to that release.
The 317.75 MB (303.03 MiB) installer includes the offline WebView2 installer and the bundled culling model.

The Windows installer is unsigned. A signing certificate is not configured;
signed client distribution, clean Windows installation without an existing
WebView2 runtime and every GPU configuration remain unverified. Do not disable
Windows protection. Updates are installed manually using the installer.

The entire Studio is not fully offline: retouch/lasso models and fonts may be
downloaded, and two optional editor operations use Gemini with the user's key.
No cloud sync or public gallery hosting is added. Local data and disk originals
retain their documented boundaries.
