# FrameMind Studio 0.1.3 — 20 October 2026

Windows x64 development preview. The installer is unsigned; a signed client
release is not available. [Download and SHA-256 checksums](https://github.com/Lukedaca/framemind-studio/releases/tag/v0.1.3).

## Changes

- Culling cards show the full uncropped frame. Double-click for original-resolution
  detail, or select up to four frames with `+` and compare them side by side.
- Choose a region in the full frame, link crop positions or move them independently,
  and inspect at physical 1:1 or 2:1 scale. Arrow keys move the crop; K/R/X apply
  to the active frame. Region metrics assist manual review without changing
  automatic suggestions. The source is the imported original or embedded RAW JPEG.
- Repeated analysis in the same application session reuses completed measurements
  of the exact same inputs. Scores and groups are recalculated. `Remeasure all`
  bypasses the cache; restarting the application requires new measurement.
- Engine `local-1.3` requires preview and native-sample detail to agree before
  relative sharpness alone can reject a frame in a verified series. Native
  comparisons require sufficient evidence and matching source dimensions.
- Grouping reuses pair evidence already collected during admission, avoiding
  a second all-pairs pass. Scene checks, group limits and manual choices remain.

## Verification

All 144 tests across 22 files, TypeScript, web and desktop frontend builds passed.
Browser and native WebView2 checks covered four-frame comparison and its limit,
linked/independent regions, 1:1 and 2:1 display, and manual decisions across reruns.
The checks used display pixel ratios 1.5 and 1.25 respectively. Worker checks
verified pixel equality with the decoded original, source hashes, cache reuse
and forced remeasurement. Culling external requests and page errors were zero.

A read-only run measured 114 authorized sports JPEGs and preserved all source
SHA-256 hashes. The final scoring/grouping replay returned 94 keep / 17 review /
3 reject. This is one calibration set, not a general accuracy or speed benchmark;
the final replay did not decode the photos again.

The local 0.1.3 update was installed and opened. Its executable matched the actual
installer payload, and all 12 existing IndexedDB/localStorage files were unchanged
before first launch. Native comparison used a separate QA profile and identifier.
See [Windows installation and verification](../desktop.md) for the evidence boundaries.

## Limits and data

Fixed automatic samples can miss a small sharp subject. Culling does not recognise
eyes, expressions, the decisive moment or focus on a particular subject. Scores
are technical indicators, not probabilities of photographic quality. More labeled
shoots, cameras and real RAW sets still need calibration.

RAW uses an embedded JPEG, not sensor development. Selected region positions and
measurement cache are not persisted across application sessions. Original files
are not overwritten or deleted by culling. Keep originals and independent backups.

The whole Studio is not fully offline: retouch/lasso models and fonts download,
and optional Gemini editor operations send a photo/preview with the user's own
API key. This release does not add face/eye detection or cloud culling.

The installer includes an offline WebView2 prerequisite, making it about 219 MiB.
Installation on clean Windows without an existing runtime and compatibility with
every GPU remain unverified. A checksum verifies matching bytes, not a publisher
signature. See the release assets for the exact download hash.
